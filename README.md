## 👨‍💻 ABOUT ME

Hey! I'm **Animesh Barun**, a Data Engineer at **ZS Associates**, based in Pune, India.

I specialize in building data pipelines and scalable data platforms using Python, PySpark, Databricks, AWS and SQL.

I'm particularly interested in distributed computing, Lakehouse architecture, API ingestion and designing reliable, production-ready data systems.

- ⚡ Passionate about scalable data engineering.
- 🏗️ Interested in modern Lakehouse architectures.
- 🔍 Exploring idempotency, incremental ingestion and pipeline reliability.
- 🚀 Constantly experimenting with new engineering patterns.
